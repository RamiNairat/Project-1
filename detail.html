Social Media Analytics Dashboard

A dashboard project designed to organize social media statistics and present account growth in a simple and understandable way.

The Challenge

Social media statistics can be difficult to compare when information changes regularly. The goal of this project was to create a simple system that could organize account information and make changes easier to understand.

Project Visual

The Solution

The project collects social media information and stores it so that changes can be compared over time. The dashboard organizes the information into a clear layout so users can quickly view account statistics.

The design focuses on keeping the interface simple. Information is separated into clear sections and important statistics are easy to identify.

Dashboard Preview

Results

The finished project provides a more organized way to view social media statistics. It allows account information to be compared while keeping the interface simple and easy to navigate.
